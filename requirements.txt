# Inferensi YOLO lewat ONNX + cv2.dnn (app/yolo_onnx.py), jadi
# torch/torchvision/ultralytics TIDAK lagi dibutuhkan saat runtime.

# .venv ~1,3 GB -> ~540 MB.

# Install:
#   ./scripts/setup_minimal.sh
# Manual:
#   python3 -m venv .venv
#   .venv/bin/pip install -r requirements.txt
# Verifikasi:
#   .venv/bin/python scripts/verify_env.py
#
# Catatan:
#  - opencv WAJIB varian *headless* (GUI pakai PyQt5, bukan cv2 GUI);
#    jangan ganti ke opencv-python biasa (duplikat .so Qt).
#  - Ekspor .pt -> .onnx (sekali, saat training) butuh torch+ultralytics;
#    itu langkah dev di mesin training, BUKAN dependensi runtime di kapal.
#  - Peta sudah app/slim_map.py murni Qt -> tanpa folium/pyqtwebengine.
#  - fuzzy/geometri/kontrol jalan di C (core/) -> tanpa scipy/scikit-fuzzy.
# ============================================================
